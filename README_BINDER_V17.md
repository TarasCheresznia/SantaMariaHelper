# Santa Maria Helper V17 — клавиши биндера

1. Распакуйте архив в новую папку и запустите `build_exe.bat` на Windows с Python.
2. Откройте «Бинды» → «Создать» → «Записать клавиши». Щёлкните по полю и нажмите F6 или Ctrl+Alt+K. Заполните название и текст, нажмите «Сохранить».
3. Включите «Биндер активен» в верхней части вкладки. Откройте обычный «Блокнот» Windows и нажмите записанную комбинацию. Для триггеров используйте раздел «Триггеры», например `.ку` → `Привет`.
4. В играх с повышенными правами/защитой от ввода синтетические нажатия могут не срабатывать. Функциональность проверяется сначала в Блокноте. Не назначайте системные сочетания Windows.

При захвате клавиши движок временно останавливается, чтобы не вводить тексты поверх редактора.

Облачный ИИ и локальная база правил не изменялись. Сборка на Windows и ввод в игре здесь не проверялись.
