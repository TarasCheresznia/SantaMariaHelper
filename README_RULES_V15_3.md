# Santa Maria Helper V15.3 — обновление базы правил

Это **инструменты загрузки и проверки**, а не уже полная выгрузка форума.

## Как собрать базу

1. Под Windows с Python установите зависимости проекта (`pip install -r requirements.txt`).
2. Запустите `update_rules_only.bat` или `python update_rules_only.py`.
3. После завершения появятся `forum_rules.json`, `forum_topics.json`, `forum_sync_report.json`.
4. По `section_audit` проверьте найденные, загруженные и недоступные темы; сравните список с форумом.

Исправлен обход вложенных разделов XenForo, страниц /page-2 и исключена повторная загрузка одной темы, найденной в родительском и дочернем разделах. При ошибках остаются предыдущие закешированные темы.

**Важно:** автообход ограничен публичными страницами. Темы за авторизацией и страницы, доступ к которым заблокирован, программа не получает. Отчёт о нуле ошибок не гарантирует, что охвачены абсолютно все правила.

Этот пакет НЕ меняет код Cloudflare. Для вопроса ИИ клиент должен сначала найти подтверждённые пункты в `forum_rules.json` и передать их в `materials.rules`.
