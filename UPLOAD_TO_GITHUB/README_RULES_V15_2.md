# Santa Maria Helper V15.2 — проверка базы правил

## Как пользоваться

1. Соберите Windows-приложение через `build_exe.bat` или запустите `start_silent.pyw` после установки зависимостей.
2. Нажмите «Обновить форум». Дождитесь завершения загрузки.
3. В папке пользовательских данных приложения откройте `forum_sync_report.json` — в `section_audit` содержится список обработанных тем, количество успехов и ошибок по каждому разделу. Рядом хранятся `forum_rules.json` и `forum_topics.json`.
4. Сравните список тем с форумом; если есть failed, повторите загрузку. Кеш успешных тем сохраняется.

Обход: общие правила, государственные, криминальные и семейные организации; закреплённые и обычные темы и страницы подразделов. Отчёт показывает именно реально обнаруженные темы, но сам по себе **не гарантирует** 100% полноту или актуальность.

Облачный Worker и Groq API-ключ менять не нужно. Клиент продолжает посылать найденные пункты с вопросом, а сервер не должен выдавать ответ без подтверждённых материалов.

Примечание: в реальном Windows EXE база сохраняется в пользовательских данных и может обновляться независимо от исходников. Не публикуйте API-ключ в архивах.
