SANTA MARIA HELPER V36 - ЗАГРУЗКА НА GITHUB

1. Распакуйте ZIP на ПК.
2. Откройте папку UPLOAD_TO_GITHUB.
3. На GitHub в репозитории: Add file -> Upload files.
4. Перетащите СОДЕРЖИМОЕ папки UPLOAD_TO_GITHUB (все файлы и подпапки), а НЕ саму папку.
5. Убедитесь, что .github/workflows/build-windows.yml находится в корне репозитория.
6. Нажмите Commit changes.

Не загружайте туда приватные данные, ключи и пользовательские аккаунты.
Репозиторий для автообновления нужно будет настроить отдельно.
