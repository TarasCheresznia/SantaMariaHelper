# Santa Maria Helper V16 — адаптивная компоновка

* Левая панель раскрывается по наведению, ширина адаптируется к окну; можно закрепить в Настройках.
* Длинные названия разделов переносятся по строкам, доступен вертикальный скролл и подсказка с полным названием.
* Ctrl++ / Ctrl+- / Ctrl+0 меняют масштаб UI (75–135%). В настройках доступны кнопки + и −.
* Список найденных правил и полные тексты разделены вертикальным перетаскиваемым разделителем.
* Минимальный размер окна 720×490. При минимальном размере проверяйте доступность скролла и бокового меню.

Работа с правилами, биндером, командами и облачным Worker оставлена без изменений.
Нужна реальная проверка на Windows и экранах с масштабированием 125–150%.
