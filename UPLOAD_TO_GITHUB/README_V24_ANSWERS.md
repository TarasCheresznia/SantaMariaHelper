# Santa Maria Helper V24 — исправление ответов

Изменения в `main.py`:

- Кнопка **Найти ответ** справа под полем вопроса.
- **Enter** отправляет вопрос, **Shift+Enter** делает перенос строки.
- Пока выполняется запрос, повторные запросы не запускаются.
- При временных HTTP 429/500/502/503/504, таймаутах и разрывах соединения клиент делает до трёх попыток с короткими паузами.
- HTTP 422 (нет достаточных доказательств), а также прочие постоянные ошибки не вызывают бесконечных повторений.
- Пустые ответы модели не считаются успешными.

Важное ограничение: это исправление устойчивости клиента, а не изменение модели Groq или Cloudflare Worker. При исчерпании квоты Groq, долгом сбое или нерелевантной базе приложение всё ещё может не ответить. Пароль раздела разработчика, логотипы, биндер и данные сохранены из V23.

Сборка: `build_exe.bat` в Windows; готовая программа при успешной сборке — в `dist`.

Проверено: синтаксис Python и целостность ZIP. Реальный запуск графического интерфейса и работа на Windows не проверены в этой среде.
