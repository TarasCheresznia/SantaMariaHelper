SANTA MARIA HELPER V12 — тестовая версия

Изменения:
- Обновлены цвета, размеры текста, скругления и отступы без удаления функций V11.3.
- Левая панель с иконками и раскрытием при наведении сохранена.
- Вместо простыни текста ответы нейросети имеют отдельные блоки: ответ, правила, команды, что проверить.
- Нет фиктивного «ИИ»: для полноценных ответов требуется свой OpenAI API-ключ и действующий API-баланс.
- API не вызывается без ключа, а ошибка не маскируется простынёй локальных совпадений.
- Команды в ответе дополнительно проверяются по retrieved базе.

Windows: установите Python, запустите build_exe.bat. Полученный файл dist\SantaMariaHelper.exe запускается без терминала.

Важно: Windows-сборка и глобальные клавиатурные триггеры в этой среде не тестировались. Полнота форума не подтверждена. Функционал AI требует подключения к интернету и ключа API.
