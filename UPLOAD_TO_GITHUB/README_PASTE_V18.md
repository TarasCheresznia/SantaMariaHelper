# Santa Maria Helper V18 — вставка через Ctrl+V

**Изменение:** текст обычных биндов, текстовых триггеров и действие `TEXT` в макросах теперь вставляется через системный буфер обмена Windows (`CF_UNICODETEXT` + `Ctrl+V`), а не печатается по буквам. Русский текст и многострочные сообщения поддерживаются.

**Важно:** каждый бинд заменяет текущее содержимое буфера обмена своим текстом. Старый буфер не восстанавливается, чтобы не создавать гонки с приложением-получателем.

Клавиши для запуска биндов и `KEY` в макросах продолжают эмулироваться как клавиши; вставка относится к тексту. Триггер `.ку` сначала удаляется с помощью Backspace, после чего вставляется заданный текст.

## Проверка
1. На Windows распаковать ZIP в отдельную папку, запустить `build_exe.bat` (требуется Python для сборки).
2. Создать `F7` → `Привет, Santa Maria!`, активировать биндер, нажать F7 в Блокноте.
3. Проверить `Ctrl+V` в Блокноте — там должен вставиться текст последнего бинда (признак использования буфера).
4. Проверить макрос `TEXT Первая строка`, `WAIT 500`, `TEXT Вторая строка`.
5. Проверить текстовый триггер `.ку` → `Привет`.

Облачный Worker, правила и админские команды не менялись. Работа на реальном Windows и в GTA RP здесь не тестировалась; игры могут блокировать синтетический Ctrl+V.
