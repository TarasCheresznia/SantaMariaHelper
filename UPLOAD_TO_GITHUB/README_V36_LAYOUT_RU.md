# Santa Maria Helper V36 — улучшенные списки

## Что изменено

- **Для разработчиков → Администраторы:** увеличенное окно 900×630, отдельная большая область со списком слева; фильтр по логину и уровню; список прокручивается; справа — отдельная панель создания/изменения выбранного пользователя.
- **Для разработчиков → Редактор команд:** увеличенное окно 1050×650; слева список уровней **1 (2), 2 (3), 3 (4), 4 (5), ЗГА, ГА, Спец админ**, рядом список команд выбранного уровня; сверху поиск; справа — редактирование команды, уровня и описания.
- **Раздел «Команды»:** под поиском теперь собственный список доступных уровней с числом команд; выбор уровня показывает команды именно этой ступени, «Все доступные уровни» возвращает полный список по правам пользователя.
- Логика разграничения прав и локальные пользовательские профили V35 не менялись.
- Файл `commands_custom.json` хранится в `%LOCALAPPDATA%/SantaMariaHelper/` и продолжает поддерживать ручные изменения из редактора.

## Установка

Распаковать архив отдельно, закрыть старую программу через трей, собрать `build_exe.bat`, запустить `dist/SantaMariaHelper.exe`.

## Ограничения

Аккаунты и редактируемые команды остаются локальными. На другие ПК они не синхронизируются автоматически. Проверены синтаксис Python, имеющиеся 27 автоматических тестов и целостность архива. Визуальная работа Qt на Windows **не проверена**.
