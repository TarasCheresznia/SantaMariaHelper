# V30 — иерархия всех загруженных правил

- Левое дерево: раздел → тема → пункт → вложенный пункт (если номер позволяет).
- Все 942 исходные записи доступны в списке, ограничение в 150 записей убрано.
- Щелчок на пункте дерева открывает полный текст и ссылку на исходную тему.
- В `rules_structure_audit.json` приведены числа записей по темам и ограничения проверки.

Внимание: **не подтверждена полнота относительно живого форума**. Исходный парсер может терять под-пункты в таблицах, раскрывающихся блоках и вложенных списках; здесь исправлено отображение всех ранее импортированных записей, но не доказано полное 1:1 соответствие форуму.

После сборки проверьте правила, особенно темы ГОС, Ghetto, Mafia и Capture. При запуске может автоматически обновляться кеш; оценивать полноту нужно по новому отчёту синхронизации.
