Santa Maria Helper V14.1 — импорт/экспорт профилей

Откройте Профили -> Загрузить профиль из файла для импорта JSON с триггерами/биндами/макросами. Выберите имя профиля, подтверждайте перезапись только при необходимости. Выберите Сохранить профиль в файл для передачи профиля другу.

Формат файла: массив JSON записей, совместимый с профилями V14. Валидируются все записи перед сохранением; максимальный размер файла 2 МБ, до 1000 записей.

build_exe.bat создаёт Windows EXE. На Windows функциональность GUI необходимо проверить отдельно.
