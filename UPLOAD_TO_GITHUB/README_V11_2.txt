Santa Maria Helper V11.2 — исправления оконного режима

- Боковая панель СЛЕВА. В свернутом виде иконки; наведение разворачивает.
- Перемещение окна: за темную верхнюю полосу с заголовком Santa Maria Helper (не за кнопки).
- Изменение размера: перетащить правый нижний угол (захват) или границы окна в Windows.
- Убран текст «Источник:» из карточки найденного правила. URL остается в базе для проверки актуальности и ответов по источникам.
- Окно закреплено поверх обычных окон Windows (Qt.WindowStaysOnTopHint). В играх с эксклюзивным полноэкранным режимом видимость не гарантируется.

EXE: запустить build_exe.bat на Windows при наличии Python. Windows GUI тест на этой машине не проводился.
