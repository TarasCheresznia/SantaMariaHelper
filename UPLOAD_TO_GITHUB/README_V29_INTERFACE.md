# Santa Maria Helper V29 — исправления интерфейса

- Ссылки «Открыть правило на форуме» из ответа ИИ теперь обрабатываются через QTextBrowser.anchorClicked и открываются только во внешнем браузере для `https://forum.santamaria-rp.com/`.
- Страницы «Правила» и «Команды»: удалён большой нижний блок предпросмотра; единственный список занимает доступное пространство. Двойной щелчок по строке открывает полный текст в отдельном окне.
- Длинные строки предварительного просмотра переносятся. При изменении размера окна запускается перерасчёт высоты строк. Для исключительно длинных правил предпросмотр ограничен 550 символами, но полный текст доступен по двойному щелчку.
- Убрана строка «Уровень: ...» в окне просмотра админских команд.
- Скорректирован стиль вертикальной полосы прокрутки и область ответа ИИ.
- База, биндер, настройки Cloudflare Worker и сам Worker не изменялись.

Сборка: `build_exe.bat`. Создавайте EXE из этой папки, не смешивая с предыдущими сборками.

Проверки: `python -m py_compile main.py`; `node --check cloudflare-worker/worker.js`; 16 тестов unittest прошли. Запуск GUI и EXE на Windows в этой среде не выполнялся.
