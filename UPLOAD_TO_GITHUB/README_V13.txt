SANTA MARIA HELPER V13 — бесплатный локальный ИИ

В этой версии платный OpenAI API заменён на локальную Ollama. Интерфейс, разделы правил и команд, биндер, профили, окно-оверлей и боковое меню сохранены из V12.

ПЕРВЫЙ ЗАПУСК
1. Установите Ollama для Windows: https://ollama.com/download/windows
2. Запустите Ollama и оставьте её работать в фоне.
3. Откройте Santa Maria Helper → Настройки → «Скачать модель».
4. По умолчанию qwen2.5:3b (~1,9 ГБ); для слабых ПК можно выбрать qwen2.5:1.5b (~1 ГБ).
5. Дождитесь конца загрузки, нажмите «Проверить ИИ» и перейдите в Santa Maria Helper.
6. Откройте «Правила» → «Обновить форум» для актуализации источников.

ИИ не работает без установленной локальной модели, не гарантирует юридически/административно верные выводы и опирается только на загруженные выдержки. Никаких платных API-ключей.

СБОРКА WINDOWS EXE
Распаковать, запустить build_exe.bat; dist/SantaMariaHelper.exe — один файл приложения. Установка модели Ollama остаётся отдельной, EXE не содержит веса модели. Глобальные триггеры и GUI требуют проверки на Windows.
