# V31.1 — категории слева

В левой панели «Правила» показаны **только категории (разделы)**. Темы, пункты и подпункты там не отображаются. Выбор категории фильтрует полный список правил в центральной области. Повторный щелчок по выбранной категории снимает фильтр.

Все исходные данные и другие функции сохранены. Проверены синтаксис и структура файлов. Работа UI на Windows не проверялась.
