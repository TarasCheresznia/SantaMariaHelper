# Santa Maria Helper V19 — обработка ошибок в вопросе

- Пользователь видит «Попробуйте задать вопрос ещё раз…» вместо внутренней ошибки сервера и сообщения о ненайденных правилах.
- Поиск учитывает отдельные очевидные опечатки русских слов (переставленные, пропущенные буквы), используя словарь из загруженных правил.
- Исправление выполняется только для поиска. Исходный вопрос отправляется облачному ИИ без подмены, номера и наказания не генерируются корректором.
- При неоднозначном исправлении исходное слово сохраняется, чтобы не подменять смысл.
- Это не полноценный грамматический анализ сложных предложений и не обучение языковой модели.
- Cloudflare Worker менять не требуется.

Соберите EXE через build_exe.bat; проверьте в приложении вопросы «Что за убисйтво без причины?» и «Какая накаазние за дм?», затем неизвестный вопрос.
