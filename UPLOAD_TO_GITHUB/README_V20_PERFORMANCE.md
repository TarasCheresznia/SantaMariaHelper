# V20 — исправления отзывчивости и точности поиска

- Локальный индекс правил строится один раз при загрузке; поиск кандидатов для облачного ИИ больше не перебирает все 942 правила с дорогостоящими нечёткими сравнениями на главном потоке.
- Для сложного вопроса требуется совпадение более чем одного смыслового признака, чтобы случайные совпадения не объединялись в ложные выводы.
- Поиск во вкладке правил отложен на 180 мс после последнего символа и не сортирует всё при пустой строке.
- Подпись панели: Santa Maria Binder.
- Ctrl+Enter / Ctrl+Return в поле ИИ отправляет вопрос; обычный Enter оставляет возможность писать несколько строк.

## Проверка
В распакованной папке `python -m unittest discover -s tests -v`; затем `build_exe.bat` на Windows. Новый файл EXE не проверялся на Windows в среде разработки.

## Важные ограничения
Семантическое понимание неоднозначных нарушений нельзя гарантировать одним ускорением поиска. При нехватке свидетельств приложение должно предложить уточнить вопрос, а не утверждать нарушение. Живой форум и полнота 942 записей независимо не проверены. Cloudflare Worker менять не нужно.
