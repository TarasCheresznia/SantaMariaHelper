# Santa Maria Helper V26 — анализ смысла вопроса

## Что изменилось

Сначала программа обращается к POST /interpret, где Groq анализирует свободный вопрос на русском (включая опечатки и разговорные формулировки), предлагает поисковые запросы и выбирает названия разделов из реального каталога. Затем локальный поиск по базе находит конкретные записи и второй запрос POST /answer проверяет описанную ситуацию строго по этим записям. Запрещено выдумывать наказания или соединять unrelated пункты правил. Если фактов недостаточно, модель задаёт уточнение.

Нет заранее прописанных конкретных фраз: поиск определяется смысловой интерпретацией модели.

## ОБЯЗАТЕЛЬНО: обновить Cloudflare Worker

Старый Worker знает только /answer. Без замены worker.js приложение использует резервный локальный поиск, и семантический анализ не будет работать полноценно.

1. Откройте Cloudflare Dashboard → Workers & Pages → santa-maria-helper-api → Edit code.
2. Замените содержимое скрипта на `cloudflare-worker/worker.js` из этого архива.
3. Нажмите Deploy. Секрет `GROQ_API_KEY` не трогать и никому не показывать.
4. Проверьте GET `/health`: должен появиться параметр `semantic: true`.
5. Соберите приложение через build_exe.bat или GitHub Actions.

## ВАЖНО

Одна проверка вопроса теперь обычно использует 2 вызова Groq (интерпретация и ответ), что увеличивает расход бесплатной квоты. Возможны задержки и rate limit: при ошибках сервис покажет локальные пункты, но это не будет считаться подтверждённым ответом ИИ. Доступный без аутентификации Worker допускает расход чужими пользователями — перед публичным релизом настройте rate limiting / abuse protection.

В базе 942 записи из ранее выгруженных 34 тем. Полнота форума не гарантирована. Разметка исходных правил могла потерять нюансы; ответы сверяйте с форумом. Никакая модель не гарантирует идеальных ответов.
