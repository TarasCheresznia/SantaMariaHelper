# Santa Maria Helper V22 — раздел «Для разработчиков»

Откройте Настройки → «🔒 Для разработчиков». После ввода заданного владельцем пароля открываются адрес Cloudflare Worker и репозиторий GitHub Releases. Кнопка «Закрыть настройки разработчика» скрывает их снова.

Обычные пользователи сохраняют доступ к биндеру, профилям, масштабу, проверке обновлений и проверке Cloudflare.

**Ограничение безопасности:** это защита от случайного изменения технических настроек, а не криптографическая защита исходного кода или настроек на компьютере пользователя. Пароль проверяется локально, а значения Cloudflare/GitHub хранятся локально. Никогда не помещайте секрет GROQ_API_KEY внутрь EXE; он должен оставаться секретом Cloudflare.

Для сборки Windows EXE используйте `build_exe.bat` или GitHub Actions.
