# Santa Maria Helper V33 — переработка команд, правил, биндера и ИИ

## Что действительно изменено

1. **Команды администратора.** Объединены прежние 108 команд и команды со всех 10 присланных скриншотов 7-го уровня. Список теперь содержит **188 уникальных команд** в алфавитном порядке. Команды не запускаются автоматически — это справочник. Для новых команд отмечен источник `source`. Некоторые команды доступны только при соответствующих игровых правах; состав команд зависит от сервера.
2. **Категории правил.** Слева только шесть разделов, с количеством записей. В центре записи сгруппированы по названиям 34 тем; внутри темы сортируются по натуральной нумерации (`1`, `1.1`, `1.2`, `1.10`, `2`). Полный оригинальный текст и ссылка доступны двойным нажатием. Нельзя гарантировать, что скачанная база покрывает все правила на форуме: это те 942 записи, которые уже были собраны.
3. **Поисковый индекс.** Исправлено разделение слов: `союзы.` теперь находится так же, как `союзы`, в отличие от V32. Это было конкретной причиной пропуска коротких важных пунктов.
4. **Облачный ИИ.** Новый последовательный алгоритм: запрос пользователя → `/interpret` с анализом смысла, опечаток и тем → индексный поиск по всем 942 записям → `/answer` с найденными выдержками. **Нет таблицы готовых ответов**. Модель может объяснять общие понятия, но выводы о наказаниях и нарушениях должна подтверждать правилом. При неоднозначности уточняет вопрос. Поскольку используется Groq, качество не гарантируется и зависит от сервера, модели и квот.
5. **Биндер и макросы.** Каждая сохранённая запись показана отдельной карточкой: включённость, имя, комбинация, текст/действия. Двойное нажатие открывает редактирование. Ввод текста остаётся через Ctrl+V, профили сохраняются в `%LOCALAPPDATA%/SantaMariaHelper/profiles`.
6. **Значок приложения.** HELPER — значок приложения/EXE и трея, золотая пальма — внутри интерфейса.

## Установка

1. Закрой старую программу через **Выход**, а не просто крестик (иначе она остаётся в трее).
2. Распакуй весь ZIP **в новую папку**.
3. На твоём Windows-компьютере запусти `build_exe.bat`; для сборки требуется Python. Готовый файл — `dist/SantaMariaHelper.exe`.
4. В Cloudflare Worker `santa-maria-helper-api` открой **Edit code** и замени код содержимым `cloudflare-worker/worker.js`, нажми **Deploy**. Секрет `GROQ_API_KEY` сохраняется, ключ не вставляй в код или клиент.
5. Проверь `/health`: должно быть `"version":"33"` и `"configured":true`.
6. Открой **именно V33 EXE** и задай два разных вопроса: «Что такое DM и наказание?» и «Можно ли заключить союз во время поставки?». При отсутствии источника модель должна уточнить ситуацию/отметить, что это общее объяснение.

**Обновить необходимо и Worker, и EXE.** Если заменить только одно, интерфейс будет работать на прежней логике.

## Проверки

- `python -m unittest discover -s tests -v` — тесты поиска/данных и совместимости.
- `node tests/worker_v33.mjs` — тесты Worker с имитацией ответов Groq, **не** реальные вызовы.
- Windows GUI и реальный Groq здесь не проверены: не называй версию окончательным релизом, пока не испытаешь оба на своём ПК.

## Важные ограничения

- Некоторые темы используют собственную повторяющуюся нумерацию; одинаковый номер в разных главах не считается одинаковым правилом. Источник хранится в `url` и полном `text`.
- 12 из 942 записей — ненумерованные заголовки или вводные абзацы; им не назначены выдуманные номера.
- Ключ Groq должен оставаться **только** в секрете Cloudflare, не в EXE.
- Наличие текста в правилах ещё не доказывает, что конкретный игрок нарушил его — для спорных ситуаций ИИ должен учитывать обстоятельства.
- Пароль раздела разработчика — защита от случайного изменения настроек, не криптографическая защита программы.
