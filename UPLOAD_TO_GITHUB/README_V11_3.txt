Santa Maria Helper V11.3 — удобочитаемый адаптивный интерфейс

Изменения по сравнению с V11.2:
- Левая панель открывается при наведении мыши, ширина 310 px для полных названий.
- В закрытом виде остаётся колонка иконок шириной 58 px.
- Исправлена зона наведения, чтобы панель не дрожала.
- Дерево правил переносит длинные подписи; отключено многоточие и горизонтальная прокрутка.
- Длинные подписи в настройках переносятся по строкам.
- Сохранены перемещение окна, уголок изменения размера, режим поверх окон и подпись by taras_chereshnia.
