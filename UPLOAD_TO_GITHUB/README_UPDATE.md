# Santa Maria Helper V15.1 — поиск с подтверждением правил

Исправлено: короткие запросы DM/ДМ/PG/ПГ и подобные расширяются при поиске по локальной базе; Worker не отправляет запрос в Groq при пустых правилах и командах; пункт правила в ответе проверяется по ID, а его текст берётся из переданного материала.

## Развёртывание уже созданного Cloudflare Worker
1. Откройте `cloudflare-worker/worker.js` из этого архива.
2. В Cloudflare → Workers & Pages → santa-maria-helper-api → Edit code замените содержимое файла `worker.js` и нажмите Deploy.
3. Secret `GROQ_API_KEY` остаётся прежним. Не вставляйте ключ в код и не отправляйте никому.
4. Проверка `POST /answer` с пустыми `rules` и `commands` теперь даёт 422 `NO_EVIDENCE` — это ожидаемо.
5. Для проверки с контекстом используйте `test_request.json`. Ожидается объяснение DM по пункту 5.7, а не Direct Message.

## Windows
В новой версии `main.py` улучшен подбор материалов. Соберите приложение на Windows через `build_exe.bat` или GitHub Actions. Адрес уже созданного Worker нужно вписать в настройки клиента; автоматически в этот архив он не записывался.

Важно: в комплекте только частичная встроенная база (75 записей). Полнота всех правил форума пока не подтверждена. Это не замена сверке с актуальными текстами. Сервер пока не защищён от публичного злоупотребления; до массовой раздачи необходимы авторизация и лимиты.
