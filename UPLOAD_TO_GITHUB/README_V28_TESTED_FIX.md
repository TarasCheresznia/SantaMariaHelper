# Santa Maria Helper V28 — проверяемые изменения

Причина ошибки V27: найденные правила отбрасывались, если модель не воспроизводила дословную цитату длиной 12+ символов либо дополнительная модель отвечала `valid: false`. В GUI дополнительно требовалось точное совпадение полей URL+text и статус `verified`. Теперь для вопросов-терминов вида `DM` или `Что такое DM?` определение извлекается из **реальной переданной базы** без генерации; остальные вопросы анализирует Groq с привязкой к конкретным текстам, без второго блокирующего вызова модели. Ответ без найденного источника отклоняется; при неясном контексте ИИ уточняет.

**Проверено локально:** `python -m unittest discover -s tests -q` (16 тестов); `node tests/worker_integration_v28.mjs` (6 проверок c мокированным Groq), `node --check cloudflare-worker/worker.js`, `python -m py_compile main.py`; JSON и ZIP. **Не проверено:** реальный Groq, развёртывание на Cloudflare, сборка Windows EXE, запуск в GTA. Не обещаем 100% точности ответов, особенно при неполной базе или неоднозначных вопросах.

## Установка

1. Сохранить прежнюю папку V27 как резервную копию.
2. В Cloudflare Worker заменить `cloudflare-worker/worker.js` и нажать Deploy. Проверить `/health`, там должна быть `version: 28`.
3. Собрать этот проект через `build_exe.bat` на Windows с установленным Python. Распаковывать ZIP до сборки.
4. В новом EXE проверить `DM` и `Что такое DM?`; в ответе должно быть определение, полученное из вашей базы. Затем проверить вопрос «цвет одежды»: без указания мероприятия он может просить уточнение, это нормально.
5. Настройка `GROQ_API_KEY` остаётся в секретах Cloudflare, никогда в EXE.

**Безопасность:** опубликованный без лимитов Worker может тратить квоту Groq. Перед широким распространением добавить Cloudflare rate limiting / защиту от злоупотреблений. Серверные секреты не включены в архив.
