# Santa Maria Helper V35 — учётные записи администраторов

## Первый запуск

1. Собери EXE из исходников с помощью `build_exe.bat`.
2. Запусти программу. Пока учётных записей нет, появится окно **создания владельца**.
3. Введи пароль разработчика `SMRP67`, придумай **логин владельца** и **отдельный пароль администратора** (8+ символов).
4. После создания владельца откроется оверлей.

## Для разработчиков

Раздел видят только пользователи уровней **ЗГА, ГА, Спец админ**.
Вход дополнительно защищён паролем разработчика `SMRP67`.

В нём есть управление администраторами (создание логина/пароля, смена уровня, смена пароля, удаление), и редактор команд (добавить, изменить, удалить, назначить минимальный уровень).

## Уровни

- 1 (2) = команды с уровнем до 2
- 2 (3) = до 3
- 3 (4) = до 4
- 4 (5) = до 5
- ЗГА = до 6
- ГА = до 7
- Спец админ = до 8

Это **накопительные права**: администратор видит команды своего уровня и всех нижестоящих. Команды без корректного поля `level` при редактуре требуют ручной проверки.

## Профили

У каждого логина отдельная папка `%LOCALAPPDATA%\SantaMariaHelper\profiles\<id>` с профилями биндов, триггеров и макросов. Переход между аккаунтами выключает биндер и не переносит активный профиль предыдущего администратора. Существующие старые профили сохранены в прежней папке и не удаляются, но не подключаются автоматически: импортируйте нужные JSON-файлы на своём аккаунте.

## Важное ограничение

**Учётные записи локальные.** Они хранятся в `%LOCALAPPDATA%\SantaMariaHelper\accounts.json`. Созданные на одном компьютере логины **НЕ появляются автоматически у друзей**. Для общего управления учётными записями и реальных серверных прав нужна отдельная облачная авторизация (Cloudflare D1/другой backend), которой в этой версии ещё нет. Не передавайте `SMRP67` друзьям. Данные локального EXE могут быть изменены пользователем с доступом к диску: это ограничение интерфейса, а не криптографическая защита от взлома.

Редактированные команды сохраняются локально в `%LOCALAPPDATA%\SantaMariaHelper\commands_custom.json`; в GitHub Releases они не публикуются сами. Для распространения одинакового справочника нужно включать его в новую сборку или реализовать облачную синхронизацию.

Облачный ИИ остался без изменений; Cloudflare Worker менять не нужно.

## Раздать настроенные логины друзьям

На компьютере разработчика создайте логины в «Для разработчиков → Администраторы» и нажмите «Экспортировать базу аккаунтов для других компьютеров». На другом компьютере **перед первым запуском** нужно положить экспортированный файл с именем `accounts.json` в `%LOCALAPPDATA%\SantaMariaHelper\accounts.json` (создать папку при необходимости). Тогда при старте появится обычная форма логина. Можно использовать разные пароли администратора для каждого друга.

Раздел «Для разработчиков» скрыт для уровней ниже ЗГА; для ЗГА, ГА, Спец админа дополнительно требуется пароль `SMRP67`. ЗГА не может создавать или изменять аккаунты уровня выше собственного.

Правка команд: «Для разработчиков → Редактор команд» → выбрать команду или добавить новую, изменить описание/минимальный уровень → «Сохранить все». На каждом компьютере изменения локальные. Чтобы раздать изменения вручную, экспортируйте список команд и скопируйте как `%LOCALAPPDATA%\SantaMariaHelper\commands_custom.json` на другие компьютеры.
