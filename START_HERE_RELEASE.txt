SANTA MARIA HELPER — RELEASE CANDIDATE

1. Распакуйте ВСЮ папку.
2. На Windows с установленным Python запустите CHECK_RELEASE.bat.
3. Если проверки прошли, запустите build_exe.bat.
4. Ожидаемый результат: dist\SantaMariaHelper.exe.
5. В приложении: Настройки -> Проверить сервер; затем вопрос «Что такое DM и какое наказание?».
6. Проверьте биндер сначала в Блокноте, не в игре (триггер, хоткей, макрос, отдельный профиль).
7. Для сборки без локального Python: загрузите содержимое архива в GitHub-репозиторий и запустите Actions -> Build Windows EXE -> Run workflow; скачайте artifact SantaMariaHelper-Windows.

Сервер Cloudflare уже развёрнут отдельно. ZIP НЕ развёртывает сервер и НЕ содержит секрет GROQ_API_KEY.
Важное ограничение: тесты проверяют структуру файлов и синтаксис, но НЕ доказывают фактический запуск и работу биндов на Windows или доступность Groq в любой момент.
Автообновление правил может требовать интернет и зависит от доступности форума; проверить после сборки.
